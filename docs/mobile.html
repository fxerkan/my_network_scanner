MyNeS Mobile The whole network scanner, running entirely on your phone.

The mobile edition of My Network Scanner runs the complete scanning engine on-device — there is no server to run, no Docker, no pairing. It discovers, identifies and monitors every device on your home network, with the same look and feel as the web app.

My Network Scanner'ın mobil sürümü, tüm tarama motorunu cihaz üzerinde çalıştırır — çalıştırılacak sunucu yok, Docker yok, eşleştirme yok. Ev ağınızdaki her cihazı keşfeder, tanımlar ve izler; web uygulamasıyla aynı görünüm ve his.

Why a native app

Same power as the web app, nothing to host

The web app is brilliant on a home server. But sometimes you just want to open your phone, tap scan, and see what's on the Wi-Fi you're standing in. MyNeS Mobile does exactly that — the full engine, offline, in your hand.

Web uygulaması bir ev sunucusunda harikadır. Ama bazen sadece telefonunuzu açıp taramaya dokunmak ve içinde bulunduğunuz Wi-Fi'de ne olduğunu görmek istersiniz. MyNeS Mobile tam da bunu yapar — tüm motor, çevrimdışı, elinizde.

%ENGINE%

On-device scan engine

A ping / TCP-connect sweep primes the ARP cache, then reads MAC, vendor, name, type and OS — merged into one device record.

%MAC%

MAC without root

The bundled native module reads the kernel ARP/NDP cache after the sweep, so reachable hosts yield a MAC on stock Android and iOS.

%OUI%

Offline vendor lookup

The IEEE OUI table ships inside the app — vendor names resolve with no network round-trip once a MAC is known.

%NAME%

Multi-source naming

Reverse-DNS first, then mDNS/Bonjour, SSDP/UPnP and NetBIOS, falling back to an HTTP title or banner-derived guess.

%FINGER%

Type & OS fingerprint

Port-based classification refined by a banner-grab pass (HTTP/SSH/FTP/RTSP) that only probes ports already found open.

%PARITY%

Pixel-parity with web

Design tokens and icons are generated from the web app's design system, so the two clients look and feel identical.

From install to a mapped network

Install & open

Grab the build from GitHub Releases (store listings coming soon) and open it on your phone — no account, no setup.

Tap scan

The app detects the Wi-Fi subnet you're on and sweeps it on-device, priming the ARP cache as it goes.

Read your fleet

Each host resolves to MAC, vendor, name, type and OS. Rename, tag and organise exactly like the web app.

Keep watch

Re-scan any time to catch new devices, changed IPs and open ports, with alerts and history built in.
