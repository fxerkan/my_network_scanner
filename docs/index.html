See every device on your network. My Network Scanner (MyNeS): your family's user-friendly network scanner.

A self-hosted, open-source application that scans every device on your local network — routers, laptops, phones, IP cameras, consoles, smart-home appliances — and lets you manage them from a modern, user-friendly web interface. Advanced scanning, AI-powered device identification, and security analysis included.

Discovery

An IP scan misses half a home network

MyNeS listens to everything that announces itself: mDNS/Bonjour (printers, NAS, Chromecast, HomeKit), Matter, SSDP/UPnP (routers, smart TVs, cameras, consoles), Bluetooth LE (devices with no IP at all) and Zigbee/Z-Wave over MQTT.

Security

Your fleet's attack surface, worst first

The Security page shows the whole fleet's attack surface and known-CVE exposure, worst first (curated offline match, not a live feed): a weighted fleet risk score, severity distribution, a “what to fix first” list and per-device detail. Credentials are stored with Fernet symmetric encryption and sanitized on export.

Integrations & API

Plugs into the stack you already run

Settings → Integrations offers InfluxDB 2 (Grafana push), Prometheus (Grafana scrape) and the app's full REST API catalog, read live and downloadable as OpenAPI (swagger.json). Home Assistant integration works via MQTT Discovery (push) and REST/WebSocket (pull), and there is a dedicated Home Assistant add-on that runs MyNeS as a one-click Supervisor add-on — add the repository, install, and it shows up in your sidebar.

Ayarlar → Entegrasyonlar; InfluxDB 2 (Grafana push), Prometheus (Grafana scrape) ve uygulamanın tüm REST API kataloğunu sunar — canlı okunur ve OpenAPI (swagger.json) olarak indirilebilir. Home Assistant entegrasyonu MQTT Discovery (push) ve REST/WebSocket (pull) ile çalışır; ayrıca MyNeS'i tek tıkla Supervisor eklentisi olarak çalıştıran özel bir Home Assistant eklentisi vardır — depoyu ekleyin, kurun, kenar çubuğunuzda belirir.

Native · Android & iOS

The whole scanner, now in your pocket

MyNeS Mobile is a standalone native app (React Native + Expo). The phone runs the entire scanning engine on-device — no server, no Docker, no pairing. It discovers, identifies and monitors every device on your home network: MAC, vendor, name, type and OS, with the same look and feel as the web app.

MyNeS Mobile, bağımsız yerel bir uygulamadır (React Native + Expo). Telefon, tüm tarama motorunu cihaz üzerinde çalıştırır — sunucu yok, Docker yok, eşleştirme yok. Ev ağınızdaki her cihazı keşfeder, tanımlar ve izler: MAC, üretici, ad, tür ve işletim sistemi — web uygulamasıyla aynı görünüm ve his.

Quick start

Running in one command

The image is published for linux/amd64 and linux/arm64, so it runs on a Raspberry Pi or Orange Pi as-is.

linux/amd64 ve linux/arm64 için yayınlanan imaj, Raspberry Pi veya Orange Pi üzerinde olduğu gibi çalışır.

services:
  mynes:
    image: fxerkan/my_network_scanner:latest
    container_name: mynes
    # Host networking is what lets it actually see the LAN.
    network_mode: host
    cap_add:
      - NET_ADMIN
      - NET_RAW
    volumes:
      - ./data:/app/data
      - ./config:/app/config
    environment:
      MYNES_PORT: 5883
      MYNES_PASSWORD: ""
    restart: unless-stopped
docker run -d \
  --name mynes \
  --network host \
  --cap-add=NET_ADMIN \
  --cap-add=NET_RAW \
  -v "$(pwd)/data:/app/data" \
  -v "$(pwd)/config:/app/config" \
  -e MYNES_PORT=5883 \
  --restart unless-stopped \
  fxerkan/my_network_scanner:latest
git clone https://github.com/fxerkan/my_network_scanner.git
cd my_network_scanner
python scripts/run.py

Then start it with docker compose up -d and open the web UI at http://<your-server-ip>:5883. Host networking and NET_RAW / NET_ADMIN are required because MyNeS sends raw ARP frames and listens for mDNS/SSDP multicast. It does not run as root and is not privileged. From source requires Python 3.9+ and Nmap; scripts/run.py creates the virtual environment, installs dependencies, checks for nmap and starts the app. Full step-by-step setup, configuration and troubleshooting live in the Docs. Only scan networks you own.

Ardından docker compose up -d ile başlatın ve web arayüzünü http://<sunucu-ip>:5883 adresinden açın. MyNeS ham ARP çerçeveleri gönderdiği ve mDNS/SSDP çoklu-yayınını dinlediği için host ağı ve NET_RAW / NET_ADMIN gereklidir. Uygulama root olarak çalışmaz ve ayrıcalıklı değildir. Kaynaktan kurulum Python 3.9+ ve Nmap ister; scripts/run.py sanal ortamı oluşturur, bağımlılıkları kurar, nmap'i kontrol eder ve uygulamayı başlatır. Adım adım kurulum, yapılandırma ve sorun giderme için Dokümanlar'a bakın. Yalnızca sahibi olduğunuz ağları tarayın.
