## Discovery

A plain IP scan misses half a home network. MyNeS combines several protocols so the ones with
no IP still show up:

- **ARP** — fast layer-2 sweep of the local subnet
- **mDNS / Bonjour** — printers, NAS, Chromecast, HomeKit; **Matter** arrives here too
- **SSDP / UPnP** — routers, smart TVs, cameras, consoles
- **Bluetooth LE** — devices keyed by BT address, no IP required
- **MQTT** — Zigbee / Z-Wave / Tasmota via Zigbee2MQTT, Z-Wave JS or HA discovery

Each protocol is optional and isolated: a dead protocol yields nothing and logs, it never
breaks the scan.

## Identification

- **Port & service scanning** across 1000+ ports (needs Nmap)
- **Active fingerprinting** — RTSP / HTTP / SSH / FTP banners plus an NBNS (SMB/NetBIOS) probe
- **OS & connection-medium guess** — OS family and a best-effort WiFi-vs-wired guess (a scored guess, never claimed as fact)
- **OUI / vendor database** — 37,000+ IEEE vendor records with an online API fallback
- **AI identification (optional)** — bring your own Anthropic / OpenAI / OpenRouter key

## Four views

The same inventory, read four ways from the toolbar:

| View | Best for |
| --- | --- |
| **Cards / Table** | Reading attributes and bulk-editing many devices at once |
| **Graph** | The whole network at a glance — subnet gateways as hubs |
| **Topology** | The physical path: internet → router → switch/AP → device |
| **Home plan** | Dragging each device into the room where it actually lives |

## Device management

Edit a device's info, add custom attributes and manual ports. Your edits are stored separately
and **re-applied after every scan**, so a rescan never clobbers your work. A scan log
breadcrumbs what changed.

## Monitoring & alerts

MyNeS scans on a schedule, diffs consecutive scans and reports only what matters:

- New device · device offline · IP change
- MAC change (possible ARP spoofing) · newly opened port
- Under-voltage · low battery · high latency · weak signal

Delivery channels: MyNeS's own **Web Push**, a **Home Assistant** notify service, **ntfy**,
**Telegram**, **webhook**, **Slack**, **Discord** and **email**.

![The monitoring and alerts screen — scheduled scans and change notifications](https://mynes.fxerkan.com/assets/screenshots/monitoring-alerts.png)

## Security & CVE analysis

The Security page shows your whole fleet's attack surface and known-CVE exposure, worst first:
a weighted fleet risk score, severity distribution, a "what to fix first" list and per-device
detail. It's a curated **offline** match against each device's fingerprint — deliberately not a
live NVD feed. Credentials are encrypted and sanitized on export.

![The security page — fleet risk score, severity distribution and per-device CVE exposure](https://mynes.fxerkan.com/assets/screenshots/secuirty.png)

## Integrations & API

InfluxDB 2, Prometheus, Grafana, Home Assistant (MQTT Discovery + REST/WebSocket), a full REST
API downloadable as OpenAPI, and a dedicated HA add-on. See [Integrations](/integrations).

## Interface

- Modern, responsive web UI — installable **PWA**, from a 320px phone up to a TV
- Light and dark theme, following the OS preference
- Full **Turkish and English** UI

## Not sure why something's missing?

Open **Settings → Capabilities**. It lists every optional feature and, for anything inactive,
*why* — a missing tool, an unreachable broker or a privilege gap. That page exists because
"it only found two devices" is a permissions problem, not a bug.
